# BakegitsuneChord

化け狐式音楽理論は、作曲者がコード進行を直感的に扱うための音楽理論ガイドです。
ナッシュビル・ナンバー・システム（NNS）を中心に、音名、スケール、コード、コード進行を鍵盤と再生機能で確認できます。

## 公開ページ

- [化け狐式音楽理論](https://sakiikavr.github.io/BakegitsuneChord/)
- [コード聴音クイズ](https://sakiikavr.github.io/BakegitsuneChord/quiz.html)
- [BakegitsuneVST配布ページ](https://booth.pm/ja/items/8132891)

## 主な内容

- 12平均律、英字音名、スケールの解説
- メジャー／マイナーコードとNNS表記の対応
- キーを変更できる鍵盤とコード進行の再生
- 響きを聴いてコード品質を答えるクイズ

## ファイル構成

- `index.html` — 音楽理論ガイド
- `quiz.html` — コード聴音クイズ
- `assets/bakegitsune-logo.png` — 化け狐ロゴ
